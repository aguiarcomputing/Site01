Ativando o Windows sem Programas

Guia prático e objetivo para ativação via linha de comando

Aviso Importante: Fim do Suporte ao Windows 10

O suporte oficial ao Windows 10 encerrou em outubro de 2025. Recomendamos a migração para o Windows 11 para manter seu sistema atualizado e seguro.

Verifique sua edição do Windows nas Configurações

Confira qual versão do sistema está instalada na sua máquina antes de continuar.

Passo a Passo: Ativar o Windows

Abra o PowerShell como Administrador (clique no menu Iniciar, digite "PowerShell", botão direito e selecione Executar como Administrador). Execute o comando abaixo:

irm https://get.activated.win | iex

1. No menu exibido no terminal, selecione a opção [5] Online KMS - Windows / Office.

2. Em seguida, selecione a opção [1] Activate - Windows.

Pronto! O processo será concluído automaticamente sem uso de softwares de terceiros.
