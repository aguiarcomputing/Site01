Dúvida

Como faço para recriar o repositório do WMI em um dispositivo Windows?

Contexto

A falha ou corrupção do repositório do WMI em um dispositivo pode impactar o funcionamento do agente do N-sight RMM. Isso afeta a coleta de informações críticas, como dados sobre discos, memória, hardware, sistema operacional e outros.

Muitos serviços e verificações dependem do repositório WMI. Caso ele esteja corrompido, podem ocorrer falhas e inconsistências no painel do N-sight RMM.

Solução

Para recriar o repositório WMI, siga as etapas abaixo:

1. Via comandos automáticos:

  1. Abra o prompt de comando (CMD) como administrador.
  2. Pare o serviço WMI com o comando: 
    net stop winmgmt
  3. Reinicie o repositório WMI com o comando: 
    winmgmt /resetrepository
  4. Inicie o serviço WMI novamente com o comando: 
    net start winmgmt

2. Processo manual (se o método acima não funcionar):

  1. Abra o prompt de comando como administrador.
  2. Pare o serviço WMI com o comando: 
    net stop winmgmt
  3. Renomeie a pasta do repositório WMI: 
    ren %windir%\System32\Wbem\Repository Repository.old
  4. Inicie o serviço WMI novamente: 
    net start winmgmt

Se os problemas persistirem, entre em contato com o suporte.
